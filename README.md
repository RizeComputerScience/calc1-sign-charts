# Calculus I: Sign Charts and Shape (interactive lesson)

A standalone interactive lesson page for Rize's Calculus I course (catalog code `MATHS I`). No login and no backend; progress is saved in the browser's own `localStorage`.

**Live:** https://rizecomputerscience.github.io/calc1-sign-charts/

**Source:** `projects/coursedev/CALC-I/interactive/pages/sign-charts/` on Samuel's machine (`SPEC.md` the spec and build notes, `src/` the source, `build.py` the build). `index.html` here is the built page, unchanged. It defines `window.__selfCheck()` for Rize's page-health monitor (`swachtel-dev/rize-interactive-health`).
